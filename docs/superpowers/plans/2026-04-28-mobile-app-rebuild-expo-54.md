# Mobile App Rebuild (Expo 54 + NativeWind v4) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Teardown the existing bare React Native app and rebuild it as a modern Expo 54 app configured with NativeWind v4 within the Nx monorepo.

**Architecture:** Remove the legacy `mobile` app, generate a new Expo-based one, configure pnpm hoisting rules for React Native compatibility, and integrate NativeWind for styling.

**Tech Stack:** Nx, Expo 54, pnpm, NativeWind v4, Tailwind CSS.

---

### Task 1: Cleanup Existing Mobile App

**Files:**
- Modify: `nx.json` (via command)
- Delete: `apps/mobile` (via command)

- [ ] **Step 1: Remove the existing mobile app cleanly using Nx**
Run: `npx nx g @nx/workspace:remove mobile --no-interactive`
Expected: `apps/mobile` directory is removed and `nx.json` is updated.

- [ ] **Step 2: Verify removal**
Run: `ls apps/mobile`
Expected: Error indicating directory does not exist.

### Task 2: Generate Fresh Expo Application

**Files:**
- Create: `apps/mobile`

- [ ] **Step 1: Generate a fresh Expo application**
Run: `npx nx g @nx/expo:app apps/mobile --no-interactive`
Expected: New Expo app structure in `apps/mobile`.

- [ ] **Step 2: Verify generation**
Run: `ls apps/mobile/package.json`
Expected: File exists.

### Task 3: Configure pnpm Hoisting Rules

**Files:**
- Modify: `.npmrc`

- [ ] **Step 1: Append hoisting rules to root .npmrc**
Add the following to `.npmrc`:
```ini
public-hoist-pattern[]=*react-native*
public-hoist-pattern[]=*expo*
public-hoist-pattern[]=*react*
node-linker=hoisted
```
*(Note: `node-linker=hoisted` is already present, ensure it remains.)*

- [ ] **Step 2: Run pnpm install to apply changes**
Run: `pnpm install`
Expected: `pnpm-lock.yaml` updated and `node_modules` refreshed.

### Task 4: Install NativeWind and Tailwind CSS

**Files:**
- Modify: `apps/mobile/package.json`

- [ ] **Step 1: Install NativeWind and Tailwind CSS**
Run: `cd apps/mobile; pnpm add nativewind; pnpm add -D tailwindcss`
Expected: Packages added to `apps/mobile/package.json`.

### Task 5: Configure Tailwind CSS

**Files:**
- Create: `apps/mobile/tailwind.config.js`

- [ ] **Step 1: Initialize and configure Tailwind CSS**
Write to `apps/mobile/tailwind.config.js`:
```javascript
/** @type {import('tailwindcss').Config} */
module.exports = {
  content: [
    "./app/**/*.{js,jsx,ts,tsx}", 
    "./src/**/*.{js,jsx,ts,tsx}", 
    "./components/**/*.{js,jsx,ts,tsx}"
  ],
  presets: [require("nativewind/preset")],
  theme: {
    extend: {},
  },
  plugins: [],
}
```

### Task 6: Configure Babel for NativeWind

**Files:**
- Modify: `apps/mobile/babel.config.js`

- [ ] **Step 1: Add nativewind/babel plugin**
Ensure `apps/mobile/babel.config.js` looks like this:
```javascript
module.exports = function (api) {
  api.cache(true);
  return {
    presets: [
      ["babel-preset-expo", { jsxImportSource: "nativewind" }],
      "nativewind/babel",
    ],
  };
};
```

### Task 7: Set up Global CSS

**Files:**
- Create: `apps/mobile/global.css`
- Modify: `apps/mobile/src/app/_layout.tsx` (or entry point)

- [ ] **Step 1: Create global.css**
Write to `apps/mobile/global.css`:
```css
@tailwind base;
@tailwind components;
@tailwind utilities;
```

- [ ] **Step 2: Import global.css in the entry file**
Add `import "../global.css";` to the top of `apps/mobile/src/app/_layout.tsx` (or the relevant entry point generated by Nx).

### Task 8: Verification

- [ ] **Step 1: Run Nx build for mobile**
Run: `npx nx build mobile`
Expected: Build succeeds.
